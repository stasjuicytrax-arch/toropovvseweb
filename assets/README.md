# Исходные изображения

Предоставлены пользователем в `parallax_assets`. Никакая генерация или ретушь для сайта не выполнялась. Экспорт lossless WebP сохраняет все значения RGBA исходных PNG, включая прозрачные поля; равенство пикселей проверено после экспорта. Все холсты 1080 × 1920.

| Файл сайта | Исходный файл |
|---|---|
| landscape.webp | 01-landscape.png |
| sofa-person.webp | 04-sofa-person-locked.png |
| foreground.webp | 05-foreground-preserved.png |
| poster.webp | reference-approved.png |

Имена объединённого среднего плана и переднего плана в приложенной инструкции отличаются от фактических имён в папке. Использованы фактически существующие файлы, указанные в таблице.

В усиленном тесте используется чистый восстановленный пейзаж `01-landscape.png`: в `01-landscape-preserved.png` обнаружен остаточный полупрозрачный силуэт головы, который становится заметен при большом смещении. Объединённый слой человека с диваном сохранён без изменений. Восстановленный пейзаж отличается от оригинального фона; нейтральная сборка теперь не заявляется попиксельной копией Hero.png.

Три плана совмещаются по единому холсту. Герой с диваном — один слой. После отзыва о слишком слабом движении выполнена проверка увеличенных амплитуд на крайних положениях. Общий overscan 1.2; амплитуды в пикселях исходного холста: фон -24/-14, средний план 36/24, передний план 84/46. Фон движется в противоположную сторону. Полная амплитуда достигается при отклонении на 8°, интерполяция 70 мс. Амплитуды пересчитываются CSS относительно масштаба контейнера. Деформаций, вращения, изменения лица, фильтров или раздельного масштабирования нет.

Статическая заставка показывается до декодирования всех слоёв, при ошибке загрузки, без JavaScript и при prefers-reduced-motion. На широких экранах сохраняется вертикальная сцена.
