# Исходные изображения

Предоставлены пользователем в `parallax_assets`. Никакая генерация или ретушь для сайта не выполнялась. Экспорт lossless WebP сохраняет все значения RGBA исходных PNG, включая прозрачные поля; равенство пикселей проверено после экспорта. Все холсты 1080 × 1920.

| Файл сайта | Исходный файл |
|---|---|
| landscape.webp | 01-landscape-preserved.png |
| sofa-person.webp | 04-sofa-person-locked.png |
| foreground.webp | 05-foreground-preserved.png |
| poster.webp | reference-approved.png |

Имена объединённого среднего плана и переднего плана в приложенной инструкции отличаются от фактических имён в папке. Использованы фактически существующие файлы, указанные в таблице.

Варианты `preserved` выбраны после сравнения сборки с одобренным кадром: RGB-значения нейтральной композиции совпадают с `reference-approved.png` попиксельно. Альфа-канал внешней кромки отличается; overscan убирает внешнюю кромку за пределы контейнера.

Три плана совмещаются по единому холсту. Герой с диваном — один слой. Общий overscan 1.04; амплитуды в пикселях исходного холста: фон 2/2, средний план 6/4, передний план 18/10. Амплитуды пересчитываются CSS относительно масштаба контейнера. Деформаций, вращения, изменения лица, фильтров или раздельного масштабирования нет.

Статическая заставка показывается до декодирования всех слоёв, при ошибке загрузки, без JavaScript и при prefers-reduced-motion. На широких экранах сохраняется вертикальная сцена.
