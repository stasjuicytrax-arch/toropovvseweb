# Прототип реакции на наклон

Тестовая страница: https://stasjuicytrax-arch.github.io/toropovvseweb/

Движение запускается сразу при открытии. Если браузер разрешает получать ориентацию без запроса, реакция на наклон подключается автоматически. В браузерах, требующих разрешение, появится подсказка коснуться самой сцены. После касания подтвердите системный запрос. Отдельной панели кнопок нет; центр определяется автоматически.

Проверка механики на предоставленной пользователем сцене: пейзаж, герой с диваном и передние цветы. На экране только фотография: имя, ссылки и тестовая панель убраны по просьбе пользователя. Происхождение слоёв и параметры сборки описаны в `assets/README.md`. Движение усилено после проверки углов кадра, чувствительность увеличена до полного диапазона при 8° наклона.

## Запуск

В этой папке: `python -m http.server 4173 --bind 127.0.0.1`.
Открыть http://127.0.0.1:4173 на этом компьютере. Наведение курсора проверяет глубину без датчиков.

Для физического телефона нужен доверенный HTTPS-хостинг. HTTP по локальному IP не подходит для проверки датчиков. В браузерах с `requestPermission()` запрос вызывается только осознанным касанием сцены с подсказкой. При открытии страница сначала молча подписывается на показания: если ранее выданное разрешение действует, дополнительного касания не требуется. Разрешение браузера нельзя гарантированно получить автоматически.

## Что проверить на телефоне

- Первое появление: автоматическое движение длится 3,6 секунды и затухает.
- Разрешение: автоматический запуск без запроса там, где это разрешено; подсказка только при необходимости; согласие и отказ; отсутствие показаний за 5 секунд после согласия.
- Небольшие наклоны во всех направлениях: ограниченная амплитуда, сглаживание.
- Первая поза телефона становится нейтральной автоматически.
- Поворот в горизонтальное положение: новая калибровка.
- Уход в другую вкладку: движение останавливается, датчик отключается. Возврат: тихое переподключение и новая калибровка. Автоматическая анимация затухает за 3,6 секунды и не зацикливается.
- При системном уменьшении движения сцена статична.
- На тестовом экране нет заголовка, сайтов или статуса. Подсказка «Коснись фото» появляется только если браузеру нужно разрешение на датчики; после ответа исчезает.
- Совмещение слоёв, лицо и положение ног при крайних наклонах; отсутствие пустых кромок.
- До загрузки слоёв, при ошибке изображений, без JavaScript и в режиме уменьшения движения видна статическая заставка.

Данные датчиков обрабатываются только в браузере, не сохраняются и не отправляются на сервер. Сторонних библиотек и сетевых зависимостей нет. Реальная плавность и направление движения требуют проверки на физическом iPhone и Android.

Документация API: https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static

Проверки без зависимостей: `node --check app.js` и `node --test tests/tilt.test.cjs`. Они проверяют обработку состояний; ощущения и плавность наклона проверяются на физическом устройстве.
