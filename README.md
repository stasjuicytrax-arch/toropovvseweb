# Прототип реакции на наклон

Тестовая страница: https://stasjuicytrax-arch.github.io/toropovvseweb/

На телефоне откройте ссылку в Safari или Chrome, нажмите «Включить наклон» и разрешите доступ, если браузер попросит. Удобную позу телефона можно сохранить кнопкой «Задать центр».

Изолированная проверка механики; не финальный дизайн сайта. Исходные изображения проекта не изменены. Оформление и короткие описания проектов будут определены после получения ассетов и изучения сайтов.

## Запуск

В этой папке: `python -m http.server 4173 --bind 127.0.0.1`.
Открыть http://127.0.0.1:4173 на этом компьютере. Наведение курсора проверяет глубину без датчиков.

Для физического телефона страницу нужно разместить на доверенном HTTPS-хостинге. HTTP по локальному IP не подходит для проверки датчиков. В браузерах с `requestPermission()` запрос вызывается только нажатием «Включить наклон». Автоматического запроса при входе нет.

## Что проверить на телефоне

- Первое появление: автоматическое движение длится 3,6 секунды и затухает.
- Разрешение: согласие, отказ, повторная попытка; отсутствие показаний за 5 секунд.
- Небольшие наклоны во всех направлениях: ограниченная амплитуда, сглаживание.
- «Задать центр»: текущая поза телефона становится нейтральной.
- Поворот в горизонтальное положение: новая калибровка.
- Пауза, продолжение, уход в другую вкладку: движение останавливается, датчик отключается.
- При системном уменьшении движения сцена статична.
- Четыре ссылки неподвижны и доступны независимо от разрешения.

Данные датчиков обрабатываются только в браузере, не сохраняются и не отправляются на сервер. Сторонних библиотек и сетевых зависимостей нет. Реальная плавность и направление движения требуют проверки на физическом iPhone и Android.

Документация API: https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static
