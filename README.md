# Стас Торопов — мобильный hero

Текущий вариант на согласование: https://stasjuicytrax-arch.github.io/toropovvseweb/?v=mobile-2

Только мобильная композиция: предоставленная фотография, исходный логотип и четыре проекта в плашках Liquid Glass. Фото и логотип скопированы без изменения содержимого файлов. На широком мониторе показывается та же мобильная колонка; широкая версия будет проектироваться после согласования.

## Стекло и движение

Эффект основан на пользовательском рецепте «Жидкое стекло.md»: один SVG-фильтр и одна карта смещения для всей страницы; отдельный span-подложка под содержимым ссылки; преломление по краям в поддерживающем Chromium; матовый blur-фолбэк. В Safari/Firefox используется фолбэк по условию рецепта. Проверен Chromium; фактический вид на Safari требует проверки на устройстве пользователя.

Фотография неподвижна. CSS-анимация кратко показывает логотип и подписи, не меняя стеклянную подложку. При prefers-reduced-motion вступление отключено. При недоступности backdrop-filter подложка становится плотнее. Датчики, параллакс и 3D к текущей странице не подключены.

Шрифт Onest 400/600 расположен локально, лицензия OFL — `assets/fonts/OFL.txt`. Во время работы страницы нет запросов к CDN.

## Запуск и проверка

Сборка не требуется. `python -m http.server 4174 --bind 127.0.0.1` из этой папки, затем http://127.0.0.1:4174/.

Проверки текущей страницы: `node --check liquid-glass.js`, проверка ссылок, фокуса, загрузки фотографий и шрифтов, зон нажатия и отсутствия переполнения в работающем браузере на 390×844 и 320×568.

Предыдущие эксперименты сохранены в Git и отдельных файлах. Они не загружаются текущей главной страницей. Направление и ограничения: `DESIGN.md`.
