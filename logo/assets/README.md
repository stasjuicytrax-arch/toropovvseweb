# Сад с логотипом — происхождение ассетов

Создано 4 ноября 2026 года встроенным инструментом ChatGPT Imagegen. Три генерации: непрозрачный дальний план и два отдельных прозрачных плана. Средний и передний планы используют первое изображение как референс композиции и освещения. Исходные PNG скопированы в `logo_generated` рядом с checkout репозитория; для сайта экспортированы lossless WebP с проверкой полного совпадения RGBA.

Все сгенерированные холсты имеют размер 941 × 1672. `logo.png` — неизменённая копия предоставленного `Stas_Toropov_Logo_2.png`, 810 × 179. Логотип не генерировался заново и не перерисовывался.

Композиция: глубокий сад при взгляде сверху; логотип в центре; два ближайших яруса растений. Масштаб всей сцены 1.28, амплитуды по условному холсту 1080 × 1920: фон -30/-18, логотип 8/6, средний план 48/34, передний план 108/66. Движок и разрешения общие с фототестом. При выключенном JavaScript, уменьшении движения или ошибке загрузки отображаются статический дальний план и исходный логотип.
