# Объёмный логотип

Текущий тест `/logo/` — настоящая WebGL 3D-сцена. Растровые планы сада в ней не используются.

Контуры оригинального `Stas_Toropov_Logo_2.png` получены из альфа-канала, векторизованы и экструдированы. Шрифт не подменялся. Логотип имеет толщину 0.38 единицы, фаски, графитовые лицевые стороны и серебристые металлические торцы. Три скруглённых объёмных портала стоят на z=-8, -2.5 и 8. Движется перспективная камера; взаимные перекрытия, отражения и тени вычисляются в 3D.

## Поведение

- Вступление до 3.2 секунды; реальный ввод прерывает его.
- Наклон телефона, курсор, касание при недоступности датчиков и стрелки клавиатуры меняют перспективу. Escape центрирует камеру.
- Разрешение датчиков запрашивается только по касанию, когда браузер этого требует.
- После стабилизации камера прекращает перерисовку. Скрытая вкладка отключает датчики и RAF.
- При уменьшении движения остаётся неподвижный 3D-кадр.
- При отсутствии WebGL или JavaScript отображается оригинальный логотип на светлом фоне.
- Растровые изображения, сгенерированные для предыдущей гипотезы сада, сохранены в `assets` как история эксперимента и не загружаются этой страницей.

## Сборка

`npm ci --ignore-scripts`, затем `npm run build:logo`.

Публикуется уже собранный `spatial.js`; на странице нет зависимости от CDN. Three.js 0.187.0, MIT, лицензия в `licenses/three-LICENSE.txt`. Сборщик esbuild используется только локально. Potrace используется только как инструмент подготовки вектора и не включён в браузерный bundle.

При смене исходного логотипа: `python scripts/prepare-logo.py`, `node scripts/trace-logo.cjs`, `npm run build:logo`. Подготовка маски использует Pillow; файл PNG пользователя не изменяется.

`npm test` проверяет геометрию проёмов, попадание логотипа в кадр, отсутствие перекрытия передним порталом при крайних наклонах, работу датчиков, разрешений, уменьшения движения и освобождение обработчиков.

Архитектура: `src/main.js` — сцена, свет и материалы; `src/geometry.js` — проёмы и камера; `src/motion.js` — управление. Направление: `DESIGN.md`.
